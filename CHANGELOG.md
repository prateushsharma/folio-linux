# Changelog

## 0.1.0-alpha — 2026-11-22

First repository release of Folio-Linux:

- Stateful offline-first book library in SQLite with bookmarks and annotations.
- Virtualized PDF canvas with single-page, facing-page and continuous modes.
- Warm paper, sepia, white and inverted reading themes; page brightness control.
- Pen, freehand marker, text highlights, note pins and non-destructive PDF export.
- Search and text selection; optional embedded research webview with browser fallback.
- Desktop application dashboard, native tabs, session restore and shortcut handling.
- One-process opening of PDFs via a local IPC socket for better Linux integration.
- Per-user Linux installation script and GitHub Actions test workflow.

**Alpha limitations:** OCR, pressure-sensitive stylus, margin expansion, independent split-reference pane, EPUB, and fully featured undo/redo are not yet implemented. A Linux GUI user acceptance test is still needed.
