# Folio-Linux roadmap

## v0.1 — First runnable alpha (included)
- Home dashboard and direct-open PDF behavior
- Saved book progress, reading states and tab restoration on demand
- Single, two-page facing and continuous scroll layouts
- Reading themes and brightness dimming
- Native PDF text search and selection
- Freehand pen, marker, highlight selected text, ink eraser, sticky note
- Bookmark, contents outline and research sidebar
- Optional embedded Google search or external browser search
- Non-destructive annotation database and PDF annotation export

## v0.2 — Reading refinements
- Actual cover thumbnails with bounded disk thumbnail cache
- Separate cover page in facing mode, RTL mode and edge-of-page gestures
- Multiple pen colors and adjustable widths in floating palette
- Undo/redo, stylus pressure handling, better selection and highlighting
- Password-protected documents, improved PDF link navigation
- Accurate search-all results, annotation editing/deletion panel

## v0.3 — Study workspace
- Independent reference pane pinned to another page
- Expanded writing margins (stored separately)
- Highlight and note exports as Markdown/HTML
- Clipboard snapshots of text/figures
- More precise line-level selection and OCR for scans

## v1.0 — Polished production release
- Mature tests on Linux Wayland/X11, accessibility audit
- EPUB, localization and good input device coverage
- Installer and AppImage/Flatpak packaging
- Profiling against 1000-page documents and graphics tablet QA
- Security and license review, automatic release builds

Features in the roadmap are **not** claimed to exist in v0.1.
